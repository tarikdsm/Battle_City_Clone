# Battle City Remake — Game Design Document

**Doc:** 00 · **Status:** Approved design (2026-07-20) · **Audience:** all contributors (human + agents)

This is the top-level design reference. Detailed rules live in [01-fidelity-spec.md](01-fidelity-spec.md); technical decisions in [02-architecture.md](02-architecture.md); presentation in [03-art-direction.md](03-art-direction.md) and [04-audio-direction.md](04-audio-direction.md); content in [05-content-levels.md](05-content-levels.md).

## 1. Vision

A faithful remake of Namco's **Battle City** (NES, 1985) for the modern web. The gameplay — rules, timings, feel, and fun — is the original's, reproduced precisely. The presentation — a stylized 2.5D diorama with dynamic lighting, particles, synthesized modern-chiptune audio, and adaptive music — is built to surprise.

**One-line pitch:** the Battle City you remember, looking and sounding the way your memory pretends it did.

## 2. Design pillars

Every decision is tested against these, in priority order:

1. **NES-faithful fun.** Rules, speeds, and timings match the original. If a modern flourish changes an outcome the NES wouldn't produce, the flourish loses. Presentation may only add information, never change simulation.
2. **Readability first, spectacle second.** The 13×13 grid, tank facing, bullet paths, and terrain types must be instantly readable at a glance — effects never obscure play.
3. **Stunning but weightless.** 2.5D visuals, dynamic light, particles, adaptive music — all procedurally generated, all running at 60 FPS, even on mid-range mobile.
4. **Zero friction.** Loads fast, plays in any browser, installable as a PWA, playable offline, from title screen to shooting in under 10 seconds.

## 3. Product overview

| Fact | Decision |
|---|---|
| Platform | Web browser (desktop + mobile), installable PWA, offline-capable |
| Players | 1P, and 2P local co-op (shared keyboard and/or two gamepads) |
| Rendering | Real-time 3D (Three.js), orthographic tilted "2.5D diorama" camera |
| Assets | 100% procedural — models, effects, music, and SFX generated by code |
| Language | English (UI and docs) |
| Content | 35 original NES stages + 12 new "Neo Campaign" stages + map editor |
| Persistence | Local only (progress, settings, high scores, custom maps in localStorage) |
| Monetization / accounts / online | None. Out of scope. |

## 4. Game modes

- **Campaign (1P / 2P co-op):** the 35 original stages in order, looping after 35 as in the NES. Stage select allows starting from any previously reached stage (progress persisted).
- **Neo Campaign (1P / 2P co-op):** 12 new stages using only original mechanics/terrain, tuned to late-game difficulty. Unlocked from the start.
- **Construction (map editor):** modern take on the original Construction mode — paint terrain, define the 20-enemy wave, test-play instantly, save locally, export/import as a share code.
- **Custom stage play:** play any saved/imported custom stage in 1P or 2P.

## 5. Screen flow

```
Boot ─▶ Title ─▶ Main menu ─▶ (Campaign | Neo | Construction | Custom | High scores | Settings)
                    │
Campaign/Neo ─▶ Stage select ─▶ Stage intro ("STAGE N") ─▶ Gameplay ⇆ Pause
                                            ▲                  │
                                            │        stage clear ─▶ Tally ─┘ (next stage)
                                            │        base lost / lives out ─▶ Game over ─▶ High-score entry? ─▶ Title
```

- **Title:** logo, "press any key/tap", subtle attract camera drift over a diorama.
- **Main menu:** vertical list, keyboard/gamepad/touch navigable.
- **Stage intro:** classic curtain moment reimagined as a camera fly-in; shows stage number and (campaign) enemy roster preview.
- **Tally:** per-player destroyed-tank counts by type × points, totals, then advance.
- **Game over:** "GAME OVER" treatment; if score qualifies, arcade-style initials entry (3 chars) into the local top-10.
- **Pause:** freezes simulation, dims scene, shows resume/restart/quit + quick volume.

## 6. Core loop (unchanged from NES)

Defend the eagle base at the bottom of the field while destroying the stage's 20 enemy tanks, which spawn from the top. Brick is destructible cover; steel, water, trees, and ice modulate movement and shots. Power-ups dropped by flashing enemies swing the battle. Lose all lives or lose the base → game over. Full rules with exact numbers: [01-fidelity-spec.md](01-fidelity-spec.md).

## 7. Controls

| Action | P1 keyboard | P2 keyboard | Gamepad (either player) | Touch |
|---|---|---|---|---|
| Move | WASD | Arrow keys | D-pad / left stick (4-way latched) | Virtual stick (left) |
| Fire | J (hold = autofire at cap) | Numpad 0 / Right Ctrl | A / Cross | Fire button (right) |
| Pause | Esc / P | Esc / P | Start | Pause icon |
| Menu navigate | WASD/Arrows + Enter | — | D-pad + A | Tap |

- Movement is 4-directional, latched to the dominant input axis (no diagonals), matching NES feel.
- Gamepads hot-plug; first pad = P1 unless P1 uses keyboard, then it becomes P2. Bindings remappable in Settings.
- Touch shows overlay controls only on touch devices; layout is responsive (portrait and landscape).

## 8. Scoring, lives, progression

As per the NES: 100/200/300/400 points for Basic/Fast/Power/Armor tanks, 500 per power-up collected, one bonus life at 20,000 points, 3 lives to start (per player). Scores are per-player in 2P. Local top-10 high-score table with initials. Details and edge cases: fidelity spec §12.

## 9. HUD

Modernized version of the NES side panel, right-docked (bottom-docked in portrait touch):

- **Enemies remaining to spawn:** grid of mini tank icons (decrements on spawn, as NES).
- **Per player:** lives count, score (live), star-tier pips.
- **Stage number** with flag.
- Transient world-space score popups (+100 etc.) at kill location — additive information only.

## 10. Settings & accessibility

- Volume: music / SFX sliders, mute on window blur (default on).
- Video: quality preset (Auto/Low/Medium/High), screen-shake toggle, flash-reduction toggle.
- Controls: remap keyboard bindings per player; gamepad mapping view.
- Accessibility: enemy types distinguishable by silhouette (never color alone), optional high-contrast outline mode, reduced-motion honors `prefers-reduced-motion` (disables shake/slow-mo, keeps gameplay identical).

## 11. Out of scope (v1)

Online multiplayer, accounts/cloud saves, achievements, leaderboards beyond local, level-sharing backend (share codes are copy-paste strings), gameplay mods/remixes (new enemy types, new power-ups), localization beyond English.

## 12. Glossary

| Term | Meaning |
|---|---|
| Tile | 1/13 of the field side; the NES 16×16 px unit. All layouts are 13×13 tiles. |
| Subcell | Quarter of a tile (NES 8×8 px). Brick damage and collision resolve at subcell precision. |
| Unit (u) | Internal length unit: 1 tile = 16 u, 1 subcell = 8 u. |
| Tier | Player star upgrade level 0–3. |
| Carrier | The 4th/11th/18th enemy of a stage; flashes and drops a power-up when hit. |
| Base / eagle | The structure at bottom-center whose destruction ends the game. |
| [CAL] | A constant pending calibration against the NES reference (see fidelity spec §16). |
